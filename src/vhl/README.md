# Vintage Lang

This is the higher level language of the vintage family. This language aims to be simple and effective and address some nagging issues that I have with using C.

## Features it Should Have
* Module Support
* Defer/AtExit Statements
* File Reading
* Optional Arguments
* Select Statment (i.e., switch over string comparison)
* SIMD (single input multiple data) operations

## Features that I have added
* File Writing
* Array Support
* Functions
* Loop Constructs
* Composite println function (multiple types in one command)
* RPN Math Evaulation
* Conditional Code Execution (RPN Evaluation)
